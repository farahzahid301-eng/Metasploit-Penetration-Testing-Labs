## Overview

This project documents a practical penetration testing lab performed using Kali Linux and Metasploit Framework in a controlled virtual environment.

The objective of this lab was to understand the basic workflow of penetration testing, including setting up the environment, configuring Metasploit modules, and analyzing security testing concepts.


## Lab Environment

- Kali Linux
- Windows 7 Virtual Machine
- Metasploit Framework


## Lab Steps Covered

### 1. Kali Linux Setup
- Installation and configuration of Kali Linux environment.

### 2. Target Machine Setup
- Windows 7 virtual machine used as a controlled testing environment.

### 3. Metasploit Framework
- Configuring listener settings.
- Understanding payload configuration.
- Checking IP address and port settings.
- Performing controlled exploitation testing.

### 4. Reverse Session
- Establishing a reverse session in the lab environment.
- Understanding communication between testing machine and target machine.


## Learning Outcomes

- Understanding penetration testing workflow.
- Learning Metasploit Framework basics.
- Understanding payload and listener concepts.
- Gaining practical exposure to ethical hacking techniques.
